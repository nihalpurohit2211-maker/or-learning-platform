Topic 1.1

Introduction to OR & Mathematical Formulation

Operations Research (OR) is the systematic application of quantitative mathematical methods to decision-making problems. An LPP has three foundational pillars:

1. Decision Variables

Quantities to be determined (e.g. \(x_1, x_2\)). Must be non-negative: \(x_j \ge 0\).

2. Objective Function

Single linear equation to maximize profit or minimize cost: \(\text{Max/Min } Z = \sum c_j x_j\).

3. Structural Constraints

Linear restrictions on resource consumption: \(\sum a_{ij} x_j \le b_i\) or \(\ge b_i\).

Key Assumptions of LPP (Exam Favourites):
  • Proportionality: Output/profit scales strictly linearly with variable value (no bulk discounts).
  • Additivity: Total resource usage equals the direct sum of individual usages (no synergistic effects).
  • Divisibility: Solutions can be continuous fractions (e.g., 2.75 hours).
  • Certainty: All coefficients (\(c_j, a_{ij}, b_i\)) are deterministic constants.
Topic 1.2

Graphical Method & The 4 Special Cases (2 Variables)

The Graphical method is applicable when there are exactly 2 decision variables. The optimal solution always lies at one of the Corner Points (Vertices) of the convex feasible region.

1. Unique Optimal Solution

A single distinct corner point maximizes/minimizes the objective value \(Z\).

2. Multiple / Alternative Optima

Occurs when the objective line is parallel to a binding constraint line: \(-\frac{c_1}{c_2} = -\frac{a_{11}}{a_{12}}\). Infinite points along the line segment are optimal.

3. Unbounded Solution

Feasible space is open to infinity in the direction of optimization. \(Z \to \infty\).

4. Infeasible Solution

No overlapping area satisfies all constraints simultaneously (feasible region is empty \(\emptyset\)).

Topic 1.3

Standard Simplex Method (All \(\le\) Constraints)

Used when all RHS \(b_i \ge 0\) and all constraints are \(\le\). Add non-negative Slack Variables \(S_i \ge 0\) with objective coefficient \(0\).

Simplex Tableau Execution Rules:
1. Compute \(Z_j = \sum C_{Bi} a_{ij}\)
2. Compute Indicator / Net Evaluation: \(\Delta_j = C_j - Z_j\)
3. Optimality Check (Max Z): If ALL \(C_j - Z_j \le 0\) → STOP! OPTIMAL SOLUTION REACHED.
4. Entering Variable (Key Column): Max positive \(C_j - Z_j\)
5. Leaving Variable (Key Row): \(\theta = \min \left\{ \frac{X_{Bi}}{a_{ik}} : a_{ik} > 0 \right\}\)
6. Pivot Element: \(p = \text{Intersection of Key Row & Key Col}\)
7. Row Transform: \(R_{pivot}^{(new)} = \frac{R_{pivot}^{(old)}}{p}\), \(R_i^{(new)} = R_i^{(old)} - a_{ik} R_{pivot}^{(new)}\)
Topic 1.4 & 1.5

Big-M (Penalty Cost) & Two-Phase Methods

When constraints contain \(\ge\) or \(=\), slack variables alone cannot form an initial identity basis matrix.

Constraint Type Variables Introduced Coeff in Max Z Coeff in Min Z Initial Basis
\(\le b_i\) + S_i 0 0 S_i
\(\ge b_i\) - S_i \text{ (Surplus)} + A_i \text{ (Artificial)} -M +M A_i
= b_i + A_i \text{ (Artificial)} -M +M A_i
🚨 Infeasibility Test in Big-M / Two-Phase:

If the final simplex table satisfies the optimality condition (\(C_j - Z_j \le 0\)) BUT at least one artificial variable \(A_k\) remains in the basis with a positive value (\(X_{Bk} > 0\)), the problem has NO FEASIBLE SOLUTION (Infeasible).

Topic 2.1

Transportation Problem (IBFS & MODI Optimality)

Shipping from \(m\) origins (supply \(a_i\)) to \(n\) destinations (demand \(b_j\)) at minimum total cost \(\sum \sum c_{ij} x_{ij}\).

Step 1: Finding Initial Solution (IBFS)

1. North-West Corner (NWCR): Allocate top-left cell \((1,1)\), ignore costs.

2. Least Cost Method (LCM): Greedily allocate to \(\min(c_{ij})\).

3. Vogel's Approximation (VAM): Calculate row & column penalties (difference between 2 lowest costs). Allocate to lowest cost cell in max penalty line.

Step 2: MODI (u-v) Optimality Test

1. Check non-degeneracy: \(\text{Allocations} = m + n - 1\).

2. Set \(u_1 = 0\). For allocated cells: \(u_i + v_j = c_{ij}\).

3. For unallocated cells: \(\Delta_{ij} = c_{ij} - (u_i + v_j)\).

4. If all \(\Delta_{ij} \ge 0\) → OPTIMAL! If any \(\Delta_{ij} < 0\), draw a closed \(\pm \theta\) loop.

Topic 2.2

Assignment Problem & Hungarian Algorithm

Assigning \(n\) resources to \(n\) activities on a strictly 1-to-1 basis to minimize total cost.

  1. Square Matrix Check: If \(m \ne n\), add dummy row/col with zero costs.
  2. Row Reduction: Subtract each row's minimum element from all elements in that row.
  3. Column Reduction: Subtract each column's minimum element from all elements in that column.
  4. Line Covering: Draw the minimum number of horizontal/vertical lines (\(L\)) to cover all zeros.
    • If \(L = n\) → Optimal reached! Make zero assignments.
    • If \(L < n\) → Find min uncovered element \(k\). Subtract \(k\) from uncovered cells, add \(k\) to intersection cells, leave single-covered cells unchanged. Repeat line covering.
  5. Zero Assignment: Box unique zeros \([0]\) in rows/cols and cross out \((\times)\) competing zeros.
Topic 2.3

Sequencing Problems (Johnson's Rule & Graphical 2-Job)

Johnson's Algorithm (n Jobs, 2 Machines A → B)

1. Find minimum processing time across both machines.

2. If minimum time is on Machine A → Schedule job FIRST (Left).

3. If minimum time is on Machine B → Schedule job LAST (Right).

4. Eliminate scheduled job and repeat.

n Jobs, 3 Machines (A → B → C) Conversion

Condition: \(\min(A_i) \ge \max(B_i)\) OR \(\min(C_i) \ge \max(B_i)\).

If valid, create fictitious machines: \(G_i = A_i + B_i\) and \(H_i = B_i + C_i\). Apply Johnson's Rule on \(G\) and \(H\).

Simplex Special Cases Cheat-Sheet

  • Optimal Solution: All \(C_j - Z_j \le 0\) (for Max) or \(\ge 0\) (for Min).
  • Infeasible Solution: Optimality condition satisfied, BUT artificial variable \(A_k\) is still in basis with \(X_B > 0\).
  • Unbounded Solution: In key column, all entries \(a_{ik} \le 0\). (No valid \(\theta = X_B / a_{ik}\)).
  • Alternative Optima: A non-basic variable has \(C_j - Z_j = 0\) at the optimal table.
  • Degeneracy: Tie in minimum ratio rule \(\theta\). Basic variable becomes \(0\) in next iteration.

Transportation & Assignment Cheat-Sheet

  • Non-degeneracy in TP: Must have exactly \(m + n - 1\) allocations. If less, add \(\epsilon \approx 0\).
  • MODI Optimality: For empty cells \(\Delta_{ij} = c_{ij} - (u_i + v_j) \ge 0\).
  • Maximization TP/AP: Subtract all values from matrix maximum \(c'_{ij} = \max(C) - c_{ij}\).
  • Hungarian Line Rule: If lines \(L < n\), subtract min uncovered \(k\) from uncovered cells and add to intersections.
  • Johnson 3-Machine Rule: Valid if \(\min(A) \ge \max(B)\) OR \(\min(C) \ge \max(B)\).
