Simplex Special Cases Cheat-Sheet

  • Optimal Solution: All \(C_j - Z_j \le 0\) (for Max) or \(\ge 0\) (for Min).
  • Infeasible Solution: Optimality condition satisfied, BUT artificial variable \(A_k\) is still in basis with \(X_B > 0\).
  • Unbounded Solution: In key column, all entries \(a_{ik} \le 0\). (No valid \(\theta = X_B / a_{ik}\)).
  • Alternative Optima: A non-basic variable has \(C_j - Z_j = 0\) at the optimal table.
  • Degeneracy: Tie in minimum ratio rule \(\theta\). Basic variable becomes \(0\) in next iteration.

Transportation & Assignment Cheat-Sheet

  • Non-degeneracy in TP: Must have exactly \(m + n - 1\) allocations. If less, add \(\epsilon \approx 0\).
  • MODI Optimality: For empty cells \(\Delta_{ij} = c_{ij} - (u_i + v_j) \ge 0\).
  • Maximization TP/AP: Subtract all values from matrix maximum \(c'_{ij} = \max(C) - c_{ij}\).
  • Hungarian Line Rule: If lines \(L < n\), subtract min uncovered \(k\) from uncovered cells and add to intersections.
  • Johnson 3-Machine Rule: Valid if \(\min(A) \ge \max(B)\) OR \(\min(C) \ge \max(B)\).
