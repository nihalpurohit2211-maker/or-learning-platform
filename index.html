Standard Simplex Maximization (All \(\le\) Constraints)

💡 Concept in Brief:

When all constraints are \(\le\) and RHS \(b_i \ge 0\), we introduce non-negative Slack Variables (\(S_1, S_2, S_3\)) with cost \(0\). The initial basis consists purely of these slacks, representing the origin point \((0,0,0)\) with initial profit \(Z = 0\). We iteratively climb towards vertices of higher profit.

Problem Statement: Maximize \(Z = 3x_1 + 5x_2 + 4x_3\) subject to: \(2x_1 + 3x_2 \le 8\), \(2x_2 + 5x_3 \le 10\), \(3x_1 + 2x_2 + 4x_3 \le 15\), with \(x_1, x_2, x_3 \ge 0\).

Example Set 1.2

Big-M Minimization (\(\ge\) Constraints)

4 Full Iteration Tables
💡 Concept in Brief:

When constraints are \(\ge\), subtracting surplus \(-S_i\) does not provide a positive unit vector. We add artificial variables \(A_i \ge 0\) and attach an immense penalty cost \(+M\) in the minimization objective (\(\text{Min } Z = \dots + M A_1 + M A_2\)) to forcefully purge artificial variables from the basis during pivoting.

Problem: Minimize \(Z = x_1 + x_2\) subject to \(2x_1 + 4x_2 \ge 4\), \(x_1 + 7x_2 \ge 7\), with \(x_1, x_2 \ge 0\).
Standard Form: \(\text{Min } Z = x_1 + x_2 + 0S_1 + 0S_2 + MA_1 + MA_2\) subject to \(2x_1 + 4x_2 - S_1 + A_1 = 4\) and \(x_1 + 7x_2 - S_2 + A_2 = 7\).
Table 1: Initial Tableau (Basis: \(A_1, A_2\))
Basis\(C_B\)\(X_B\) \(x_1\) (1)\(x_2\) (1) ↑ \(S_1\) (0)\(S_2\) (0) \(A_1\) (M)\(A_2\) (M) Ratio \(\theta\)
\(A_1\)M4 24 -10 10 4/4 = 1.00
\(A_2\) →M7 1(7) 0-1 01 7/7 = 1.00 ← Min (Drop Artificial)
\(C_j - Z_j\) -3M + 1-11M + 1 ↑ (Most Negative) MM 00 -
🔍 Big-M Step 1 Explanation:
• In Minimization, the entering variable is the most negative \(C_j - Z_j\). Here \(-11M + 1\) is heavily negative, so \(x_2\) enters.
• Minimum ratio ties at \(\theta = 1.00\). Rule: When regular and artificial variables tie, always drop the artificial variable (\(A_2\)) to purge it immediately.
• Pivot element is 7.

🎉 Optimal Minimization Result:
• All \(C_j - Z_j \ge 0\) for minimization (\([1/2, 0, 1/4, 0]\)). No artificial variables remain in the basis.
• Optimal Solution: \(x_1^* = 0, x_2^* = 1\) with \(\text{Min } Z^* = 1\).
Example Set 1.3

Big-M Infeasible Solution (Detection Proof)

2 Full Tables • Artificial Remains
💡 Exam Recognition Trigger:

An LPP is Infeasible if the final simplex tableau satisfies the optimality condition (\(C_j - Z_j \le 0\)), BUT at least one artificial variable (\(A_k\)) remains in the basis with a strictly positive value (\(X_{Bk} > 0\)). This mathematically proves the constraints are contradictory.

Problem Statement: Maximize \(Z = 6x_1 + 4x_2\) subject to \(x_1 + x_2 \le 5\), \(x_2 \ge 8\), \(x_1, x_2 \ge 0\).
Standard Form: \(\text{Max } Z = 6x_1 + 4x_2 + 0S_1 + 0S_2 - M A_1\) with \(x_1 + x_2 + S_1 = 5\), \(x_2 - S_2 + A_1 = 8\).
Basis\(C_B\)\(X_B\) \(x_1\) (6)\(x_2\) (4) ↑ \(S_1\) (0)\(S_2\) (0)\(A_1\) (-M) Ratio \(\theta\)
\(S_1\) →05 1(1) 100 5/1 = 5 ← Min
\(A_1\)-M8 01 0-11 8/1 = 8
\(C_j - Z_j\) 6M + 4 ↑ 0-M0-
Basis\(C_B\)\(X_B\) \(x_1\)\(x_2\) \(S_1\)\(S_2\)\(A_1\)
\(x_2\)45 11 100
\(A_1\) [ARTIFICIAL]-M3 > 0 -10 -1-11
\(Z = 20 - 3M\) M + 44 M + 4M-M
\(C_j - Z_j\) -M + 2 ≤ 00 -M - 4 ≤ 0-M ≤ 00
🚨 INFEASIBILITY PROOF: All \(C_j - Z_j \le 0\) (optimality met), BUT artificial variable \(A_1\) remains in the basis with positive value \(X_B = 3\). The constraints \(x_1 + x_2 \le 5\) and \(x_2 \ge 8\) cannot be satisfied simultaneously!

💡 VAM Algorithm Rule:

For every active row and column, calculate the Penalty = (Second Smallest Cost) - (Smallest Cost). Identify the line with the maximum penalty, and allocate as much as possible (\(\min(\text{Supply}, \text{Demand})\)) to the lowest-cost cell in that line. Cross out satisfied lines and repeat.

🔍 Step-by-Step VAM Execution:
1. First Max Penalty: Occurs at Column D2 with Penalty = \(30 - 8 = 22\). Minimum cost cell in D2 is \((O3, D2)\) with cost \(8\). We allocate \(\min(18, 8) = 8\) units. Column D2 is satisfied!
2. Second Max Penalty: Occurs at Column D1 with Penalty = \(40 - 19 = 21\). Min cost cell in D1 is \((O1, D1)\) with cost \(19\). Allocate \(\min(7, 5) = 5\) units. D1 is satisfied!
3. Resulting IBFS Cost: \(Z = 19(5) + 10(2) + 40(7) + 8(8) + 20(7) = \mathbf{779}\). Number of allocations = \(6 = m + n - 1\) (Non-degenerate).

Simplex Special Cases Cheat-Sheet

  • Optimal Solution: All \(C_j - Z_j \le 0\) (for Max) or \(\ge 0\) (for Min).
  • Infeasible Solution: Optimality condition satisfied, BUT artificial variable \(A_k\) is still in basis with \(X_B > 0\).
  • Unbounded Solution: In key column, all entries \(a_{ik} \le 0\). (No valid \(\theta = X_B / a_{ik}\)).
  • Alternative Optima: A non-basic variable has \(C_j - Z_j = 0\) at the optimal table.
  • Degeneracy: Tie in minimum ratio rule \(\theta\). Basic variable becomes \(0\) in next iteration.

Transportation & Assignment Cheat-Sheet

  • Non-degeneracy in TP: Must have exactly \(m + n - 1\) allocations. If less, add \(\epsilon \approx 0\).
  • MODI Optimality: For empty cells \(\Delta_{ij} = c_{ij} - (u_i + v_j) \ge 0\).
  • Maximization TP/AP: Subtract all values from matrix maximum \(c'_{ij} = \max(C) - c_{ij}\).
  • Hungarian Line Rule: If lines \(L < n\), subtract min uncovered \(k\) from uncovered cells and add to intersections.
  • Johnson 3-Machine Rule: Valid if \(\min(A) \ge \max(B)\) OR \(\min(C) \ge \max(B)\).
