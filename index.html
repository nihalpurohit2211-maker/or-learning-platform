Topic 1.3 Guide

Standard Simplex Method (Maximization, All \(\le\))

Decision Roadmap + 4 Full Tables
🎯 What We Are Doing:

We start at the origin \((0,0,0)\) where all physical production is zero (\(Z=0\)) and all resources remain unconsumed (stored in Slack Variables \(S_1, S_2, S_3\)). In each table, we swap one non-profitable slack variable with the most profitable product variable (\(x_j\)) to step onto adjacent vertices of the feasible polygon until no further profit increase is possible.

⚠️ What to Keep in Mind (Exam Traps):
  • Entering Variable: Pick the most positive \(\Delta_j = C_j - Z_j\).
  • Leaving Variable: Minimum ratio \(\theta = X_B / a_{ik}\) ONLY for strictly positive \(a_{ik} > 0\). (Never divide by \(0\) or negative numbers!).
  • Optimality Stop: When ALL \(C_j - Z_j \le 0\), the current basis is mathematically optimal.

Topic 2.1 Guide

Vogel's Approximation Method (VAM) Decision Flow

🎯 What We Are Doing:

VAM is a penalty-based heuristic. The penalty of a row/column represents the opportunity cost you suffer if you fail to allocate to the absolute cheapest cell. By prioritizing lines with the highest penalty, VAM avoids severe cost penalties and produces near-optimal initial solutions.

⚠️ VAM Rules to Keep in Mind:
  • Penalty Formula: \(\text{Penalty} = (\text{2nd Lowest Cost}) - (\text{Lowest Cost})\).
  • Tie in Penalty: If two lines have the identical max penalty, pick the line containing the absolute minimum unit cost cell.
  • Degeneracy Check: Ensure exactly \(m + n - 1\) allocations at the end before testing with MODI.

Simplex Special Cases Cheat-Sheet

  • Optimal Solution: All \(C_j - Z_j \le 0\) (for Max) or \(\ge 0\) (for Min).
  • Infeasible Solution: Optimality condition satisfied, BUT artificial variable \(A_k\) is still in basis with \(X_B > 0\).
  • Unbounded Solution: In key column, all entries \(a_{ik} \le 0\). (No valid \(\theta = X_B / a_{ik}\)).
  • Alternative Optima: A non-basic variable has \(C_j - Z_j = 0\) at the optimal table.
  • Degeneracy: Tie in minimum ratio rule \(\theta\). Basic variable becomes \(0\) in next iteration.

Transportation & Assignment Cheat-Sheet

  • Non-degeneracy in TP: Must have exactly \(m + n - 1\) allocations. If less, add \(\epsilon \approx 0\).
  • MODI Optimality: For empty cells \(\Delta_{ij} = c_{ij} - (u_i + v_j) \ge 0\).
  • Maximization TP/AP: Subtract all values from matrix maximum \(c'_{ij} = \max(C) - c_{ij}\).
  • Hungarian Line Rule: If lines \(L < n\), subtract min uncovered \(k\) from uncovered cells and add to intersections.
  • Johnson 3-Machine Rule: Valid if \(\min(A) \ge \max(B)\) OR \(\min(C) \ge \max(B)\).
