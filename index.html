📘 Module 1: Linear Programming

Graphical Method • Simplex • Big-M • Infeasibility

📖 Theory: Algorithm Steps

  1. Plot each constraint as a straight line by finding x-intercept and y-intercept.
  2. Determine the valid half-plane: test origin \((0,0)\) in each inequality.
  3. The Feasible Region = convex intersection of all valid half-planes in quadrant I.
  4. Find coordinates of all Corner Points (vertices) by solving pairs of boundary lines.
  5. Evaluate \(Z\) at every corner point. Best value = Optimal Solution.
Unique Optimum
One best vertex
Multiple Optima
Z-line parallel to constraint
Unbounded
Region open, \(Z \to \infty\)
Infeasible
No overlapping region

🎯 What We Did: Evaluated \(Z\) at all 5 vertices of the feasible polygon.

📐 Formula Cheat Sheet

Multiple Optima Condition: \(\text{Slope of } Z = -c_1/c_2 = -a_{k1}/a_{k2} = \text{Slope of binding constraint}\)

Unbounded: Feasible region open in optimization direction → \(Z \to \infty\)

Infeasible: No common region → constraints are contradictory

📖 Theory: Simplex Algorithm

Canonical Form Setup
  • Slack Variable \(+S_i\): Added to \(\le\) constraints. Cost = 0.
  • Initial Basis: All slacks \(\{S_1, S_2, \ldots, S_m\}\) form identity matrix.
  • Initial \(Z = 0\) (all decision variables = 0).
Iteration Steps
  1. Compute \(Z_j = \sum C_{Bi} \cdot a_{ij}\)
  2. Compute \(\Delta_j = C_j - Z_j\)
  3. Optimality: All \(\Delta_j \le 0\) → STOP (optimal)
  4. Entering: Column with max positive \(\Delta_j\)
  5. Leaving: Row with min positive ratio \(\theta = X_B / a_{ik}\)
  6. Pivot: Gaussian row operations
Problem: Maximize \(Z = 3x_1 + 5x_2 + 4x_3\) subject to: \(2x_1 + 3x_2 \le 8\), \(2x_2 + 5x_3 \le 10\), \(3x_1 + 2x_2 + 4x_3 \le 15\), with \(x_1, x_2, x_3 \ge 0\).

📖 Theory: Why Big-M is Needed

When constraints have \(\ge\) or \(=\) signs, slack variables alone cannot form an initial identity basis. We need Artificial Variables with a huge penalty cost \(M\).

ConstraintAdd VariablesCoeff in Max ZCoeff in Min ZInitial Basis
\(\le\)\(+S_i\) (Slack)\(+0 \cdot S_i\)\(+0 \cdot S_i\)\(S_i\)
\(\ge\)\(-S_i + A_i\)\(-M \cdot A_i\)\(+M \cdot A_i\)\(A_i\)
\(=\)\(+A_i\)\(-M \cdot A_i\)\(+M \cdot A_i\)\(A_i\)
Problem: Minimize \(Z = x_1 + x_2\) subject to: \(2x_1 + 4x_2 \ge 4\), \(x_1 + 7x_2 \ge 7\), with \(x_1, x_2 \ge 0\).

🎯 What We're Doing: Both constraints are \(\ge\), so we subtract surplus \((-S)\) and add artificial \((+A)\) with penalty \(+M\) in the objective.
📐 For Minimization: Entering = most negative \(\Delta_j\). Here \(1 - 11M\) is most negative (since \(M \to \infty\)), so \(x_2\) enters.
⚠️ Key Rule: In Min: penalty is \(+M\). In Max: penalty is \(-M\). Reversing this is a common exam error!
⚠️ Tie-Breaking: If ratios tie between an artificial and a real variable, always drop the artificial first to clean up the basis.
✅ Procedure: Continue pivoting until all \(\Delta_j \ge 0\) (for Min). If all artificials leave with \(X_B = 0\), the solution is feasible and optimal.

🚚 Module 2: Transportation, Assignment & Sequencing

VAM • MODI • Hungarian • Johnson's Rule

📖 Theory

Balance Check

Total Supply must equal Total Demand: \(\sum a_i = \sum b_j\). If not, add dummy row/column with cost 0.

VAM Penalty

Penalty = (2nd lowest cost) - (lowest cost) in each row and column. Allocate to the row/col with the highest penalty, choosing the cell with the lowest cost in that row/col.

📖 Theory: MODI Steps

  1. Set \(u_1 = 0\). For each allocated cell, solve \(u_i + v_j = c_{ij}\) to find all \(u_i, v_j\).
  2. For each unallocated cell, compute \(\Delta_{ij} = c_{ij} - u_i - v_j\).
  3. If all \(\Delta_{ij} \ge 0\) → OPTIMAL. If any \(\Delta_{ij} < 0\) → can improve.
  4. Enter the cell with most negative \(\Delta_{ij}\). Draw a closed loop with \(+\theta, -\theta\) at corners.
  5. \(\theta = \min\)(allocations at \(-\theta\) corners). Reallocate. Repeat.
Testing the VAM IBFS: Allocations: (S1,D1)=5, (S1,D4)=2, (S2,D3)=7, (S2,D4)=2, (S3,D2)=8, (S3,D4)=10. Cost = 779.

Step 2: Closed Loop Reallocation

Entering cell: (S2, D2) with \(\Delta = -18\)

Closed Loop:

(S2,D2)+θ → (S3,D2)-θ → (S3,D4)+θ → (S2,D4)-θ

θ = min(allocations at - corners) = min(8, 2) = 2

New Allocations:

(S2,D2) = 0+2 = 2, (S3,D2) = 8-2 = 6, (S3,D4) = 10+2 = 12, (S2,D4) = 2-2 = 0 (leaves)

New Cost = 5(19)+2(10)+2(30)+7(40)+6(8)+12(20) = 743. Saving = 779 - 743 = 36 ✓

🎯 Loop Rule: Start at entering cell (+θ). Move horizontally/vertically to allocated cells only. Alternate + and - at each turn.
📐 After loop: Re-test with MODI. New potentials give all \(\Delta_{ij} \ge 0\) → OPTIMAL at Z* = 743.
⚠️ Exam Trap: If \(\theta = 0\) (degenerate case), the cost doesn't change but the basis changes. Don't stop!

📖 Theory: Hungarian Algorithm Steps

  1. Row Reduction: Subtract row minimum from every element in that row.
  2. Column Reduction: Subtract column minimum from every element in that column.
  3. Line Covering: Draw minimum lines to cover all zeros. If \(L = n\) → Optimal! If \(L < n\) → Step 4.
  4. Matrix Modification: Subtract smallest uncovered \(k\) from uncovered cells. Add \(k\) to intersections. Go to Step 3.
  5. Assignment: Find row/col with single zero → Box it. Cross out other zeros in its row/col.

📐 Special Cases

Maximization: Convert by \(c'_{ij} = \max(c) - c_{ij}\), then solve as minimization.

Prohibited Assignment: Set \(c_{ij} = \infty\) (or a very large M) for forbidden cells.

Unbalanced: If rows ≠ columns, add a dummy row/column with all costs = 0.

📖 Theory: Johnson's Rule

2-Machine Rule
  1. Find the smallest processing time in the entire matrix.
  2. If it's on Machine A → place that job FIRST (from left).
  3. If it's on Machine B → place that job LAST (from right).
  4. Cross off the job. Repeat until all placed.
3-Machine Extension

Applicable only if: \(\min(A_i) \ge \max(B_i)\) OR \(\min(C_i) \ge \max(B_i)\).

Create fictitious machines: \(G_i = A_i + B_i\), \(H_i = B_i + C_i\). Apply 2-machine rule on G, H.
